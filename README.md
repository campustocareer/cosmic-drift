# Cosmic Drift — Endless 3D Game

An endless single-player 3D glider built with Three.js.

## 🎮 Play
After deployment: [Play the Game](https://<yourusername>.github.io/cosmic-drift/)

## 🛠️ Tech Stack
- Three.js (WebGL)
- HTML5, JavaScript, CSS

## Controls
- Move left/right: A / D or ← →
- Mouse / Touch: steer ship
- Avoid asteroids, collect distance!
